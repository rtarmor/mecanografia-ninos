# MecaKids 🐱‍💻
Aplicación web interactiva y gamificada diseñada para que los niños aprendan mecanografía de forma divertida, visual y progresiva.

## Características
- **Lecciones guiadas:** Desde la fila central del teclado hasta palabras y frases cortas.
- **Teclado virtual interactivo:** Resalta las teclas en tiempo real mientras el usuario escribe.
- **Minijuego arcade ("Lluvia de Palabras"):** Pon a prueba la velocidad y agilidad con vidas y puntuaciones.
- **Sistema de recompensas:** Estrellas acumulables, avatares de progreso y efectos de confeti.
